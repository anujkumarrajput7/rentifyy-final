# 🏠 Rentifyy — Product Rental Platform

Rentifyy is a full-stack product rental platform designed to make it easier for users to rent everyday products for a specific period of time.

The platform focuses on products such as **furniture, cars, bikes, ACs, TVs, refrigerators, and other rental items**.

## 📌 About the Project

Rentifyy provides a platform where users can browse products available for rental, select the product they need, complete the required payment, use the product during the rental period, and return it after use.

Unlike a traditional rental model where users only pay a rental fee, Rentifyy is designed around a **product-value-based payment and return model**.

### How it works

1. 🛍️ User selects a product they want to rent.
2. 💳 User pays the required full product amount.
3. 📦 The product is provided to the user for the agreed rental period.
4. ⏳ User uses the product during the rental period.
5. 🔄 User returns the product after use.
6. 💰 After the product is successfully returned, the eligible product amount is returned to the user according to the platform's rental model.

### Example

Suppose a TV has an actual product value of **₹30,000**.

- The user pays ₹30,000 to rent the TV.
- The user uses the TV for the agreed rental period.
- After returning the TV according to the platform's conditions, the eligible ₹30,000 product amount can be returned to the user.

The platform is designed to provide a different approach to traditional product rental services.
